# lib/

Put **`libmpv-2.dll`** here (the mpv playback engine, ~120 MB — too large for the repository).

1. Open the [shinchiro mpv builds](https://github.com/shinchiro/mpv-winbuild-cmake/releases).
2. Download `mpv-dev-x86_64-<date>.7z` (the **dev** archive, not the player itself).
3. Extract `libmpv-2.dll` into this folder.

The ready-to-run download on the [Releases](../../../releases/latest) page already includes it.
