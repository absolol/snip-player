Snip Player — видеоплеер для Windows с обрезкой видео
===================================================

Устанавливать ничего не нужно: всё нужное уже лежит в этой папке.


Как запустить
-------------
1. Распакуйте архив в любую папку (например, «Документы\Snip Player» или на диск D:).
   Запускать прямо из архива не надо — сначала распакуйте.
2. Дважды щёлкните «Snip Player.exe».
3. Откройте видео: перетащите файл в окно или нажмите Ctrl+O.

Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажмите
«Подробнее» → «Выполнить в любом случае». Так бывает с любой программой не из магазина.

Нужна 64-разрядная Windows 10 или 11.


Язык
----
Плеер запускается на русском, если Windows на русском, иначе — на английском.
Сменить: шестерёнка справа внизу → «Настройки…» → «Внешний вид» → «Язык · Language».
Плеер предложит перезапуститься; открытое видео продолжится с того же места.
(English instructions are in "Read me.txt".)


Как сделать плеером для видео по умолчанию
------------------------------------------
1. В плеере: шестерёнка справа внизу → «Настройки…» → раздел «Система» →
   «Сделать плеером для видео». Права администратора не нужны.
2. Правой кнопкой по любому видео → «Открыть с помощью» → «Выбрать другое приложение» →
   «Snip Player» → «Всегда». Windows просит сделать это по разу для каждого формата
   (mp4, mkv, avi…) — сама программа назначить себя не может.

Если потом перенесёте папку с плеером в другое место — нажмите «Сделать плеером для видео»
ещё раз. Отменить — там же, «Убрать регистрацию».


Что умеет
---------
- Открывает почти любые видео (движок mpv).
- Обрезка: кнопка с ножницами или клавиша C. S — разрезать, Ctrl+X — удалить кусок,
  «Сохранить как копию» — сохранить результат (без потерь качества или быстро).
- Скриншот кадра — клавиша P (в «Изображения\Snip Player» и в буфер обмена).
- Все горячие клавиши — шестерёнка → «Горячие клавиши».


Где хранятся настройки
----------------------
В файле settings.ini рядом с «Snip Player.exe» — папку можно носить на флешке вместе
с настройками. Если плеер лежит там, куда писать нельзя (например, в «Program Files»),
настройки сохраняются в %APPDATA%\Snip Player.

Удалить плеер: «Убрать регистрацию» в настройках (если делали «Сделать плеером»),
затем просто удалите папку.


Лицензии
--------
В плеере используются FFmpeg, mpv, Qt и другие свободные программы — список и тексты
лицензий в папке «Лицензии».
