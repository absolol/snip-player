# Snip Player

Видеоплеер для Windows на Python. Открывает почти любые форматы (движок mpv), оформление меняется темами,
есть встроенный редактор для обрезки видео (сохранение через FFmpeg).

## Обрезка видео

Кнопка с ножницами на нижней панели или клавиша **C** открывает редактор прямо в той же панели.

- **S / «Разрезать»** — поставить маркер разреза в текущей позиции. Маркеры делят видео на куски.
- **ЛКМ по куску** — выделить его, **Ctrl + ЛКМ** — выделить несколько.
- **Ctrl+X / «Удалить кусок»** — пометить выделенные куски на удаление (повторно — вернуть). Если выделен
  уже удалённый кусок, кнопка называется «Вернуть кусок».
  Если ничего не выделено — кусок под курсором воспроизведения.
- **Маркер можно перетащить** мышью, **ПКМ по маркеру** — «Убрать разрез» (куски склеиваются).
- **, / .** — кадр назад / вперёд, чтобы точно встать перед разрезом.
- **Колесо мыши над таймлайном** — увеличить / уменьшить его вокруг точки под курсором (до полсекунды
  на всю ширину), **Shift + колесо** — прокрутить. Под лентой появляется полоса-обзор всего видео
  с рамкой видимого участка — её можно тянуть. При воспроизведении лента едет за курсором.
- **Звуковая волна** — полоса под кусками: видно, где говорят, где тишина, где громко. Маркеры и курсор
  проходят сквозь неё; проигранное — цветом интерфейса, удаляемое — красным. Показывает дорожку, которую
  сейчас слышно (наушники в «Звук: 2 из 3» переключают и её); при увеличении шкалы увеличивается вместе с ней.
  Строится в фоне за пару секунд (час видео — около 2 с), у видео без звука — надпись «Нет звука».
- Удаляемые куски заштрихованы на таймлайне (и в обычном просмотре), а при просмотре плеер их
  перепрыгивает — сразу видно итог.
- **Ctrl+Z / Ctrl+Y** — отменить / вернуть, «Сбросить» — убрать все разрезы и пометки.
- Кружок **«i»** — подсказки по управлению (при наведении).
- **Сохранение** — кнопка «Сохранить как копию» со стрелкой ▾ (Ctrl+S — выбранным сейчас способом):
  - **Сохранить как копию** — новый файл, имя и папку выбираете вы; исходное видео не меняется;
  - **Сохранить с удалением** — исходный файл заменяется обрезанной версией под тем же именем,
    старое видео уходит в корзину Windows (его можно восстановить). Плеер сразу открывает новую
    версию на том же месте.
  - **Сохранить куски отдельно** — каждый выделенный кусок (Ctrl + ЛКМ — несколько) в свой файл; если ничего
    не выделено — все оставленные куски. Плеер спрашивает только папку, файлы называются «имя — кусок 3.mp4»
    (номер — место куска в видео; существующие файлы не перезаписываются — «(2)»). Удаляемые куски не
    сохраняются. Для этого способа удалять ничего не нужно — достаточно разрезов.
- **Звук: 3 из 3 ▾** (только если в видео несколько звуковых дорожек — например, OBS пишет игру, микрофон
  и Discord отдельно): галочками выбрать, какие дорожки попадут в сохранённое видео (ни одной — видео без звука);
  наушники справа — послушать дорожку в плеере, чтобы понять, где что. Дорожки копируются без перекодирования,
  названия дорожек сохраняются. Выбор не запоминается: у нового файла снова отмечены все.
- **Качество** (список рядом с кнопкой):
  - **Без потерь** (по умолчанию) — разрезы точно по кадру, качество и битрейт как в исходнике.
    Видео между ключевыми кадрами и весь звук копируются байт в байт; заново кодируются только
    кадры от точки разреза до ближайшего ключевого кадра (обычно доли секунды) — с качеством
    CRF 12, визуально неотличимым от оригинала. Результат проверяется (число кадров, длина звука,
    декодирование у стыков). Для H.264/H.265 с «открытыми» группами кадров и для других кодеков
    (VP9, AV1…) видео перекодируется целиком с очень высоким качеством, звук всё равно копируется.
  - **Быстро** — всё копируется, почти мгновенно, но границы сдвигаются к ближайшим
    ключевым кадрам (до 1–2 секунд).
- **Скорость.** Перекодирование идёт на видеокарте (NVIDIA NVENC, Intel Quick Sync, AMD AMF —
  что найдётся), если она умеет нужный кодек; иначе на процессоре. Кусочки у стыков, копирование,
  звук и проверка делаются параллельно, временные файлы лежат рядом с итоговым (без копирования
  между дисками). Выбор «видеокарта / процессор» — в настройках, раздел «Обрезка и сохранение».

## Что нужно

- Python 3.10+
- `lib/libmpv-2.dll` — движок mpv (уже лежит в проекте; сборка с
  https://github.com/shinchiro/mpv-winbuild-cmake/releases, архив `mpv-dev-x86_64-*.7z`)
- Библиотеки: `python -m pip install -r requirements.txt`
- FFmpeg (понадобится для обрезки)

## Запуск

Двойной щелчок по `Запуск.bat` или в терминале:

```
python main.py
python main.py "путь\к\видео.mkv"
```

Плеер открывается одним окном: если он уже запущен, новый запуск (например, двойной щелчок по видео)
не открывает второе окно, а передаёт файл в уже открытое и поднимает его на передний план
(свёрнутое — разворачивает). Несохранённая обрезка — плеер, как обычно, сначала спросит; во время
сохранения видео новый файл не откроется. Если открытый плеер завис, через ~3 с запустится новый.

## Сборка для других людей

Папка «скачал — запустил» (без Python и FFmpeg у человека) собирается скриптом `сборка\build.py`:

```
python -m venv --system-site-packages env_сборки
env_сборки\Scripts\python -m pip install pyinstaller   (через прокси — wheel'ы curl'ом и --no-index)
env_сборки\Scripts\python сборка\build.py --7z --zip
```

Итог — `D:\claude anim\ПРОИГРЫВАТЕЛЬ — для скачивания\Snip Player\` (рядом архивы: `Snip Player.7z` — ~80 МБ, его и выкладывать, Windows 11 открывает .7z сама;
`Snip Player.zip` — ~145 МБ, для Windows 10 без 7-Zip; флаги `--7z` / `--zip` — какие архивы делать): `Snip Player.exe`,
`Прочитай меня.txt` и `Read me.txt` (по-английски), `Лицензии\` и `_internal\` (Python, Qt, libmpv, темы, ffmpeg.exe и ffprobe.exe). FFmpeg берётся
из `сборка\ffmpeg\` (облегчённая сборка gyan «essentials» 9.0.2: x264, x265, VP9, NVENC, QSV, AMF — всё, что
нужно сохранению), иначе из PATH или из папки `--ffmpeg ПАПКА`. Собранный плеер хранит `settings.ini` рядом с exe, а если туда писать нельзя
(Program Files) — в `%APPDATA%\Snip Player` (прежняя `Проигрыватель` переименовывается сама). «Сделать плеером для видео» в сборке записывает команду на сам exe.

## Плеер по умолчанию для видео

1. Настройки → «Система» → **«Сделать плеером для видео»** (или двойной щелчок по
   `Установить как проигрыватель.bat`) — плеер появится в «Открыть с помощью»
   для видео и в «Параметры → Приложения → Приложения по умолчанию» (запись только для вашего
   пользователя, права администратора не нужны). Иконка видеофайлов — `Snip Player.ico`.
2. Правой кнопкой по видео → **Открыть с помощью → Выбрать другое приложение → Snip Player → Всегда**.
   Сделать это нужно по разу для каждого формата (mp4, mkv, avi…) — Windows не разрешает программам
   назначать себя самим.

Если папку с плеером перенести, нажмите «Сделать плеером для видео» ещё раз (в настройках будет
написано «Зарегистрирован для другой папки»). Отменить — «Убрать регистрацию» в настройках или
`Удалить регистрацию.bat` (убирает всё, что записала установка; если плеер был выбран «Всегда»,
Windows при следующем открытии видео спросит, чем его открыть).

## Настройки

Шестерёнка → «Настройки…» или **Ctrl+,**. Изменения применяются сразу.

- **Воспроизведение** — продолжать с места, где остановились (по умолчанию выключено; для каждого видео своё место; досмотренное
  начинается сначала; надпись «Продолжаем с …» — только если дальше первой минуты); что делать в конце видео (остановиться / следующее в папке / повтор); шаги перемотки
  стрелками и с Shift, шаг громкости; ускорение при удержании мыши или пробела и его предел.
- **Внешний вид** — язык (русский / английский, см. ниже), основа (тёмная / светлая), цвет интерфейса и уведомлений с предпросмотром, обводка кнопок окна, кнопка «Стоп» на панели, уведомления поверх видео и сколько
  их держать.
- **Окно** — открывать новые видео в том же окне (выключение — со следующего запуска).
- **Скриншоты** — папка, формат PNG / JPG, копировать ли в буфер обмена.
- **Обрезка и сохранение** — кодировать на видеокарте или процессоре, качество и способ сохранения по умолчанию.
- **Система** — сделать плеером для видео в Windows / убрать регистрацию.

Размер и положение окна плеер запоминает сам. Всё хранится в `settings.ini` рядом с программой.

## Язык (русский / английский)

Настройки → «Внешний вид» → **«Язык · Language»**: «Русский» или «English». Пока язык не выбран, плеер берёт
язык Windows (русский, белорусский, казахский → русский, остальные → английский). Язык меняется после
перезапуска: плеер сразу предлагает «Перезапустить» (вопрос — уже на новом языке), открытое видео продолжится
с того же места. Плеер на обоих языках называется «Snip Player», скриншоты — в «Изображения\Snip Player».

Как устроено: надписи в коде — по-русски в `tr("…")` (`player/i18n.py`), английские — словарь
`player/lang_en.py` (ключ — та же русская строка). Новая надпись = `tr("…")` в коде + строка в `lang_en.py`.

## Нижняя панель

Слева направо: предыдущее видео в папке, −5 с, воспроизведение, +5 с, следующее видео · кадр назад / вперёд
(только на паузе) · время … громкость · скриншот · обрезка, шестерёнка, во весь экран.
«Предыдущее / следующее видео» видны, только если в папке есть другие видео.
Открыть файл — Ctrl+O или перетащить видео в окно.

**Шестерёнка** — быстрое меню: скорость, поверх всех окон, «Оформление…» (настройки → «Внешний вид»),
«Настройки…» и «Горячие клавиши». В углу шестерёнки — текущая скорость (не 1× — цветом акцента).
Повтор — клавиша L или настройки. Отдельного меню «Файл / Вид / Справка» в заголовке нет.
«Горячие клавиши» — окно в стиле настроек: клавиши по группам, шаги перемотки — как в настройках.

Кнопки анимированные (`player/anim_button.py`): при наведении плавно подсвечиваются, при нажатии
«проседают», включённые переключатели заливаются цветом акцента от центра, ▶ и ⏸ плавно сменяют друг друга.
Иконки — [Lucide](https://lucide.dev), и у каждой своя анимация при наведении в духе
[Lucide Animated](https://lucide-animated.com) (`player/icons.py`): шестерёнка проворачивается, уголки
«во весь экран» расходятся, волны громкости появляются по очереди, ножницы щёлкают и т. д.
Ползунок громкости выезжает при наведении на динамик. «Стоп» спрятан (включается в настройках).
В узком окне лишние кнопки плавно сжимаются к центру и исчезают, при расширении — так же возвращаются.

- **Скриншот** — текущий кадр в полном размере видео (не окна), PNG в «Изображения\Snip Player»
  с именем «видео — время.png» и сразу в буфер обмена. Поверх видео появляется надпись.
- **Повтор** — дойдя до конца, видео начинается заново; запоминается (это та же настройка, что «В конце видео
  → Повтор»). **Поверх всех окон** — плеер не уходит назад.
  Оба — в меню шестерёнки; «Поверх всех окон» между запусками не запоминается.
- В узком окне часть кнопок прячется по очереди (кадры, файлы в папке, скриншот) —
  их клавиши продолжают работать.

## Мышь

| Действие | Что происходит |
|---|---|
| Щелчок левой кнопкой по видео | пауза / воспроизведение |
| Зажать левую кнопку на видео | ускорение до 2×, сверху видна текущая скорость |
| …и тянуть влево / вправо | скорость плавно меняется от 1× до 3× |
| Отпустить | возвращается обычная скорость |
| Двойной щелчок по видео | во весь экран |

Настройки ускорения — константы `HOLD_*` в начале `player/main_window.py`.

## Заголовок окна

Свой заголовок в стиле «Капсулы» (`player/title_bar.py`): слева иконка, по центру имя файла,
справа круглые кнопки окна («закрыть» — цвета акцента темы). Иконка программы рисуется кодом
(`player/app_icon.py`) и меняет цвет вместе с темой.

Поведение окна остаётся как у обычных окон Windows (`player/window_chrome.py`): перетаскивание
за заголовок, двойной щелчок, изменение размера за края, привязка к краям экрана, Win+стрелки,
тень и скруглённые углы Windows 11, меню раскладок при наведении на «Развернуть».

### Сведения о видео

Щелчок по капсуле с именем файла открывает панель под ней: размер, длительность, формат,
общий битрейт, дата изменения, папка; у видео — разрешение, частота кадров, кодек, битрейт;
у звука — кодек, битрейт, частота, каналы. Кнопки «Копировать» (всё текстом в буфер обмена)
и «Открыть папку».
Закрывается щелчком мимо, повторным щелчком по имени или Esc. Сведения берутся у ffprobe
в фоне сразу после открытия файла (`player/media_info.py`, панель — `player/info_panel.py`).

Во весь экран сверху появляется только капсула с именем файла — вместе с панелью управления,
когда двигают мышь, и прячется вместе с ней. Щелчок по ней открывает те же сведения.

Обводка круглых кнопок уже заложена (`TitleBar.set_outline("soft" | "accent")`) и будет
включаться в настройках.

## Темы

Отдельного выбора темы нет — оформление настраивается в Настройки → «Внешний вид»:

- **основа** — тёмная или светлая (фон, панели и текст подбираются сами, всё остаётся читаемым);
- **цвет интерфейса** — восемь готовых кружков или «Свой…» (любой цвет): кнопки, шкала, выделение,
  кнопка «закрыть», иконка программы;
- **цвет уведомлений** («Повтор включён», «Скриншот сохранён», скорость 2×) — оттенок цвета интерфейса:
  как он, светлее, глубже, соседний оттенок в одну или другую сторону, — или «Свой…». При смене цвета
  интерфейса оттенки пересчитываются сами. Ниже — **предпросмотр**: кадр открытого видео и уведомление
  «Повтор включён» в выбранном цвете; при каждом щелчке по кружку оно выпрыгивает заново.

«Тема» в шестерёнке — та же основа: тёмная / светлая. Основы лежат в папке `themes/` (`dark.json`,
`light.json` — фон, панели, текст), `style.qss` — общий шаблон, куда цвета подставляются.

| Ключ | Что окрашивает |
|---|---|
| `bg` | фон окна |
| `surface` | меню и панель управления |
| `surface2` | кнопки при наведении, полоса таймлайна |
| `border` | рамки и разделители |
| `text` / `text_dim` | основной и приглушённый текст |
| `accent` / `accent_hover` | кнопка Play, прогресс, выделение |
| `accent_text` | значок на кнопке Play |
| `danger` | вырезанные куски на таймлайне |
| `video_bg` | фон под видео |
| `radius` | скругление углов (в пикселях) |
